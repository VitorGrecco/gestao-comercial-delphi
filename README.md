\# Gestão Comercial Desktop



Sistema de gestão comercial desktop desenvolvido em Delphi VCL com SQL Server.



O projeto está sendo desenvolvido com foco em boas práticas de organização, separação de responsabilidades e construção de uma aplicação desktop completa para portfólio.



\## Tecnologias



\- Delphi

\- VCL

\- SQL Server

\- ADO (dbGo)

\- Git / GitHub



\## Funcionalidades



\- Autenticação de usuários

\- Validação de senha por hash

\- Navegação por menu lateral

\- Consulta de usuários

\- Cadastro de usuários (em desenvolvimento)

\- Cadastro de clientes (planejado)

\- Cadastro de produtos (planejado)

\- Gestão de pedidos (planejado)



\## Estrutura do projeto



\- `src/Forms` - Telas da aplicação

\- `src/DataModules` - Conexão e acesso compartilhado ao banco

\- `src/Repositories` - Acesso aos dados

\- `src/Utils` - Funções auxiliares

\- `database` - Scripts do banco de dados

\- `config` - Exemplo de configuração da conexão
